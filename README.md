# Social Media Analysis

## Project Description
This project analyzes social media performance data to understand engagement, reach, likes, comments, shares, and other important metrics.

## Objectives
- Analyze social media performance.
- Clean and preprocess the dataset.
- Identify patterns and relationships in the data.
- Visualize important insights.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Files
- social_media_performance.csv
- cleaned_social_media_performance.csv
- social_media_cleaning.py
- social_media_analysis.ipynb
- correlation_heatmap.png
- outlier_boxplots.png
- relationship_plots.png

## Conclusion
The project helps understand social media performance using data analysis and visualization techniques.
